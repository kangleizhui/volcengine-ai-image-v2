# 支付流程说明

## 前置条件

> ⚠️ 如果创建订单失败，提示用户：当前API项目还未配置支付通道，请联系技能开发者配置。

## 购买套餐

1. 用户发送"套餐" → AI 展示可选方案
2. 用户选择套餐 → AI 调用 `POST /pay/create.php` 创建订单
3. AI 用 `qrencode` 生成二维码图片发给用户
4. 提醒用户打开支付宝扫码支付，支付成功后告诉 AI
5. 用户告知已支付后，AI 调 `GET /pay/query.php?order_id=xxx` 查状态
6. 返回 `status=paid` → AI 做三件事：
   a. **把密钥发给用户保存** — "🎉 支付成功！你的密钥：XXXX-XXXX-XXXX，请保存好"
   b. **自己配置好密钥**（key_manager 自动替换当前密钥，后续调用都用这个付费密钥）
   c. **告知用户已配置** — "✅ 已为你配置好密钥，现在直接发提示词给我就能生图了！"
7. 返回 `status=pending` → 告知用户还未支付成功，请稍后再试

| type | 说明 |
|------|------|
| count | 按次计费，有总次数限制 |
| daily | 包天，有到期时间，无限次 |
| monthly | 包月，有到期时间，无限次 |
| lifetime | 永久，无限次 |

## 错误处理

- 创建订单失败 → 提示：当前API项目还未配置支付通道，请联系技能开发者配置
- 查询支付失败 → 告知用户重新联系 AI 查询

## 密钥配置

支付宝密钥通过后台页面配置，存储在 `data/settings.json`：
- `alipay_app_id` — 支付宝App ID
- `alipay_private_key` — 应用私钥（PEM格式）
- `alipay_public_key` — 支付宝公钥
- `payment_notify_url` — 通知地址（留空自动检测）
