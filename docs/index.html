📖 火山AI生图 API 文档

基于火山引擎豆包大模型的图片生成接口

🔗 基础信息

Base URLhttp://www.volcengine.com:8080
格式JSON (UTF-8)
认证URL 参数 key（API密钥）

🎨 图片生成 GET

根据文字描述生成图片，支持文生图和图生图

请求 URL

GET /api/generate.php?key={密钥}&prompt={描述}&size={尺寸}&n={张数}

参数

参数必填说明
key必填API密钥（测试密钥：TEST1-ABCD-EFGH-IJKL-MNOP）
prompt必填图片描述文字，如"一只在草地上奔跑的边牧，写实风格"
size可选尺寸，默认 1024x1024，可选：512x512、768x768、1024x768、768x1024
n可选生成张数，1-4，默认 1

请求示例

curl "http://www.volcengine.com:8080/api/generate.php?key=TEST1-ABCD-EFGH-IJKL-MNOP&prompt=赛博朋克城市夜景，霓虹灯，雨夜&size=1024x1024"

响应示例

{
  "code": 200,
  "msg": "生成成功",
  "data": {
    "images": [
      {
        "url": "https://...generated.png",
        "revised_prompt": "..."

      "is_test": true,

  }
}

🔑 密钥查询 GET

查询任意密钥的状态、剩余次数和到期时间，不消耗次数

请求 URL

GET /api/key_info.php?key={密钥}

响应

{
  "code": 200,
  "msg": "ok",
  "data": {
    "is_test": true,
    "type": "count",
    "is_active": true,
    "remaining": 8,
    "daily_remaining": 9,
    "expires_at": null
  }
}

💻 各语言调用示例

Python

import requests

url = "http://www.volcengine.com:8080/api/generate.php"
params = {
    "key": "你的密钥",
    "prompt": "一只在星空下奔跑的白色边牧",
    "size": "1024x1024",
    "n": 1
}
resp = requests.get(url, params=params).json()
if resp["code"] == 200:
    image_url = resp["data"]["images"][0]["url"]
    print(f"生成成功: {image_url}")
else:
    print(f"失败: {resp['msg']}")

JavaScript / Node.js

const url = new URL("http://www.volcengine.com:8080/api/generate.php");
url.searchParams.set("key", "你的密钥");
url.searchParams.set("prompt", "水墨风格的山景，云雾缭绕");
url.searchParams.set("size", "1024x1024");

fetch(url)
  .then(r => r.json())
  .then(data => {
    if (data.code === 200) {
      console.log("图片URL:", data.data.images[0].url);
    }
  });

PHP

<?php
$url = "http://www.volcengine.com:8080/api/generate.php?" . http_build_query([
    'key' => '你的密钥',
    'prompt' => '卡通风格的森林小屋',
    'size' => '1024x1024',
]);
$resp = json_decode(file_get_contents($url), true);
if ($resp['code'] === 200) {
    echo "图片: " . $resp['data']['images'][0]['url'];
}

⚠️ 错误码说明

HTTP说明
400缺少必填参数（key / prompt）
403密钥无效、已过期、已被禁用
429测试密钥每日每IP 10次已用完
500火山引擎API调用失败或服务端配置错误
